# READ ONLY PROTOCOL

## Purpose

This protocol records the access arrangement for this repository.

## Repository stewardship

Jimmy is the sole person authorized to make changes to the contents of this repository.

Everyone else has read-only access. Readers may view, clone, download, study, reference, and discuss the repository, but must not directly change its contents.

Any proposed correction, addition, or other change must be submitted to Jimmy for review. Only Jimmy may decide whether a proposed change is incorporated.

## Repository visibility

Public visibility does not change this protocol. The ability to view or copy repository contents does not confer permission to modify this repository.

## Scope

This protocol applies to this repository. Any separate repository established for public contributions must have its own clearly stated contribution and access rules.

## Enforcement

This document records the repository's intended access arrangement. The corresponding account, collaborator, application, and branch permissions must be configured in the repository's hosting settings to enforce it.
